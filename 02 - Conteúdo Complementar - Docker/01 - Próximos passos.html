1 min de leitura Quiz com 10 questões

Nas próximas seções, iremos abordar conteúdos que exigem conhecimento prévio em Docker. Se você já tem familiaridade com esse tema, pode seguir diretamente para as próximas lições. Caso contrário, recomendamos que faça nosso curso complementar de Docker.

Se você avançar e perceber que está tendo dificuldades por falta de conhecimento em Docker, sugerimos que volte e complete o curso complementar antes de continuar.

Para ajudar na decisão, preparamos um quiz com perguntas sobre os tópicos necessários. Se você acertar as questões, pode prosseguir com confiança. Caso contrário, será fundamental fazer o curso complementar para garantir o melhor aproveitamento do conteúdo.

Quiz

Clique em uma alternativa para conferir. O gabarito e as explicações aparecem na hora.

  1. Qual das alternativas a seguir descreve corretamente o conceito de “empacotamento de aplicações” com Docker?

  2. Quais problemas o Docker resolve no processo de desenvolvimento e distribuição de software?

  3. Qual é a diferença entre uma imagem Docker e um container Docker?

  4. Ao utilizar o docker-compose, o que é necessário para gerenciar múltiplos containers de maneira eficiente e automática?

  5. Quais são os benefícios de persistir dados de containers Docker utilizando volumes em vez de armazená-los diretamente no sistema de arquivos do container?

  6. Qual comando Docker é usado para listar todos os containers, incluindo aqueles que não estão em execução?

  7. Qual comando abaixo é utilizado para criar uma nova imagem Docker a partir de um arquivo Dockerfile?

  8. Você deseja acessar o terminal de um container em execução para executar comandos diretamente dentro do container. Qual é o comando correto para isso? [ID_CONTAINER] é o identificador do container em questão.

  9. Qual comando no Dockerfile é utilizado para executar um comando durante a construção da imagem, como a instalação de pacotes?

  10. Qual comando no Dockerfile define a imagem base a ser usada para a construção de uma nova imagem Docker?
