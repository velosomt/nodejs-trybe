1 min de leitura Quiz com 10 questões

Nas próximas seções, iremos abordar conteúdos que exigem conhecimento prévio em banco de dados relacional. Se você já tem familiaridade com esse tema, pode seguir diretamente para as próximas lições. Caso contrário, recomendamos que faça nosso curso complementar de banco de dados.

Se você avançar e perceber que está tendo dificuldades por falta de conhecimento em banco de dados, sugerimos que volte e complete o curso complementar antes de continuar.

Para ajudar na decisão, preparamos um quiz com perguntas sobre os tópicos necessários. Se você acertar as questões, pode prosseguir com confiança. Caso contrário, será fundamental fazer o curso complementar para garantir o melhor aproveitamento do conteúdo.

Quiz

Clique em uma alternativa para conferir. O gabarito e as explicações aparecem na hora.

  1. Considerando uma tabela Funcionarios com as colunas ID, Nome, Salario e ID_Departamento, e uma tabela Departamentos com as colunas ID_Departamento e Nome_Departamento, qual das seguintes consultas retorna todos os funcionários junto com o nome de seu departamento, incluindo os funcionários que não estão associados a nenhum departamento?

  2. Você tem duas tabelas, Clientes e Pedidos, onde Pedidos.ClienteID é uma chave estrangeira que referencia Clientes.ClienteID. Qual seria o resultado de uma consulta SQL que usa INNER JOIN entre essas tabelas, mas não possui nenhum registro correspondente em Pedidos para um cliente específico?

  3. Qual consulta SQL corretamente retorna os três maiores salários de uma tabela Funcionarios, ordenados em ordem decrescente, excluindo empates de salário?

  4. Qual das alternativas descreve corretamente o uso da cláusula LIKE em uma consulta SQL?

  5. Você deseja selecionar registros de uma tabela Produtos onde o preço está entre R$ 100 e R$ 500. Qual das opções a seguir representa uma possível cláusula WHERE correta?

  6. Você está trabalhando com uma tabela Funcionarios e deseja selecionar todos os funcionários cujo departamento seja 'Vendas', 'Marketing' ou 'RH'. Qual das consultas a seguir representa uma possível cláusula WHERE correta?

  7. Qual comando SQL você utilizaria para remover colunas de uma tabela existente?

  8. Qual das seguintes consultas retorna todos os registros onde a terceira letra do nome do cliente é a letra 'b' e termina com qualquer sequência de caracteres?

  9. Qual das alternativas a seguir define corretamente o conceito de uma chave primária em um banco de dados relacional?

  10. Qual das seguintes afirmações é verdadeira sobre chaves estrangeiras em bancos de dados relacionais?
