> Seção 9 - Automatização e Deploy de Aplicações · Lição 10 de 11

****Questão 1**.** O que é deploy em uma aplicação?

**Justificativa:**

a) Incorreta. Escrever o código-fonte é parte do desenvolvimento, não do deploy.  
b) Incorreta. Configurar o ambiente local ajuda no desenvolvimento, mas não é deploy.  
c) Correta. Deploy é o processo de disponibilizar a aplicação para que possa ser acessada por usuários. ✅  
d) Incorreta. Criar um banco de dados é uma etapa separada, que pode anteceder o deploy.  
e) Incorreta. A depuração é um processo antes do deploy, mas não faz parte dele.  

Resposta correta: **Alternativa C**.

****Questão 2**.** Qual das seguintes opções representa corretamente a diferença entre IaaS, PaaS e SaaS?

**Justificativa:**

a) Incorreta. SaaS fornece softwares prontos, não infraestrutura. PaaS não lida com servidores físicos.  
b) Correta. IaaS oferece infraestrutura, PaaS fornece plataformas e SaaS são softwares prontos para uso. ✅  
c) Incorreta. IaaS permite gerenciamento de servidores virtuais, mas PaaS e SaaS não são serviços offline.  
d) Incorreta. PaaS pode hospedar aplicações dinâmicas, não apenas arquivos estáticos.  
e) Incorreta. SaaS é para usuários finais, não para desenvolvedores.

Resposta correta: **Alternativa B**.

****Questão 3**.** Sobre Docker e Docker Compose, qual das afirmações está correta?

**Justificativa:**

a) Correta. Docker Compose permite orquestrar vários containers simultaneamente. ✅  
b) Incorreta. Docker é usado para criar containers, não apenas imagens de sistemas operacionais.  
c) Incorreta. Containers são replicáveis em diferentes ambientes.  
d) Incorreta. Dockerfile define a construção do container, mas não exclui automaticamente containers.  
e) Incorreta. Docker é totalmente compatível com Node.js.  

Resposta correta: **Alternativa A**.

****Questão 4**.** Qual das seguintes plataformas é um serviço adequado para hospedar aplicações Node.js?

**Justificativa:**

a) Incorreta. Photoshop é um software de edição de imagem, não uma plataforma de deploy.  
b) Incorreta. Excel é uma ferramenta de planilhas, não um serviço de nuvem.  
c) Correta. Railway é uma plataforma de deploy adequada para aplicações Node.js. ✅  
d) Incorreta. VLC é um reprodutor de mídia, não uma plataforma de deploy.  
e) Incorreta. Windows Defender é um software de segurança, não um serviço de nuvem.  

Resposta correta: **Alternativa C**.

****Questão 5**.** Analise as seguintes assertivas sobre deploy e escolha a alternativa que contém apenas as afirmativas corretas.

a) I e II  
b) II e IV  
c) I, III e V ✅  
d) III, IV e V  
e) II, III e V  
**Justificativa:**

I. Correta. Docker Compose gerencia múltiplos containers simultaneamente. ✅  
II. Incorreta. IaaS fornece infraestrutura, mas também permite acesso a servidores.   
III. Correta. O deploy pode ser automatizado com GitHub Actions ou outros mecanismos de CI/CD. ✅  
IV. Incorreta. Railway possui uma camada gratuita para desenvolvedores.  
V. Correta. Variáveis de ambiente protegem informações sensíveis. ✅

Resposta correta: **Alternativa C**.
