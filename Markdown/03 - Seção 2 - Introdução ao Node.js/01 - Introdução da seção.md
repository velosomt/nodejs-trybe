# 2.1 - Introdução da seção

> Seção 2 - Introdução ao Node.js · Lição 1 de 11

## Onde estamos?

Olá, pessoal!

Nesse conteúdo, você aprenderá sobre `Node.js`, explorando algumas de suas utilizações e como criar um script simples utilizando essa tecnologia.

### Você será capaz de:

-   Entender e utilizar o sistema de módulos do `Node.js`;
-   Desenvolver scripts simples com interação do usuário;
-   Manipular arquivos através de funções de leitura e escrita.
-   Criar e gerenciar pacotes e dependências com `npm`;

## Por que isso é importante?

O conhecimento em Node.js tem se tornado essencial no mercado de trabalho, especialmente para desenvolvedores back-end. Com o crescente uso dessa tecnologia por empresas para desenvolver aplicações de alta performance e escalabilidade, a demanda por profissionais qualificados em Node.js aumenta a cada dia.

O Node.js se destaca por sua utilização do JavaScript, uma linguagem versátil e poderosa, que oferece uma curva de aprendizado mais acessível em comparação com outras linguagens de back-end. Essa facilidade, combinada com a vasta comunidade e o ecossistema rico de pacotes, torna o Node.js uma escolha estratégica para desenvolvedores que desejam se destacar no desenvolvimento web moderno.

Dominar o Node.js não só abre portas no mercado, mas também permite a criação de aplicações eficientes e robustas, essenciais para o cenário atual de desenvolvimento.
