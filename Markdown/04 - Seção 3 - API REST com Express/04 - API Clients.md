# 3.4 - API Clients

> Seção 3 - API REST com Express · Lição 4 de 20

Além do navegador, outra maneira prática de interagir com nossa aplicação é utilizando um API Client como o `Postman`, `Insomnia` ou `ThunderClient`.

-   [Postman](https://www.postman.com/)
-   [Insomnia](https://insomnia.rest/)
-   [ThunderClient](https://www.thunderclient.com/)

Esses apps são plataformas que ajudam na construção e utilização de APIs bem interessantes, pois eles simplificam as etapas do ciclo de vida de uma API e agilizam a colaboração das pessoas desenvolvedoras.

Utilizando essas ferramentas, podemos interagir com nossos projetos sem depender exclusivamente do navegador, o que torna nosso trabalho diário mais ágil e flexível.
