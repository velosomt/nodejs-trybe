# 3.15 - Interpretando Erros

> Seção 3 - API REST com Express · Lição 15 de 20

Até agora, aprendemos a tratar erros com middlewares, mas como interpretar esses erros quando eles aparecem no terminal? Muitas vezes, os erros trazem informações importantes que nos ajudam a entender o que está dando errado e como corrigir.

Neste vídeo, vamos explorar técnicas e dicas que irão te ajudar a identificar o tipo de erro, decifrar as mensagens e agir de forma adequada para resolver os problemas no seu código.
