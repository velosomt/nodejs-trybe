# 4.12 - Projeto - Talker Manager

> Seção 4 - Testes da Aplicação · Lição 12 de 13

## O que vamos fazer?

Você irá construir uma aplicação de cadastro de talkers (palestrantes) em que será possível cadastrar, visualizar, pesquisar, editar e excluir informações.

## Por que isso é importante?

O conjunto de operações conhecido como CRUD (Create, Read, Update e Delete) constituem a forma mais básica de manipular dados. Apesar disso, boa parte das aplicações de mercado giram em torno dessas quatro operações. Neste projeto, você implementará essas operações utilizando Node.js, express e o módulo fs.

Além de treinar os conhecimentos adquiridos nesta seção, você estará criando um tipo de aplicação extremamente comum no mercado e experimentando, em primeira mão, alguns dos desafios e das particularidades que essas aplicações podem trazer.

## Especificação

### O que vamos avaliar?

-   Construção da API com express;
-   Métodos HTTP;
-   Status Code;
-   Testes de Integração.

### O que devo desenvolver?

Este projeto será individual.

Você deverá construir uma API, utilizando os métodos HTTP e *Status Code* corretos. Além de escrever testes de integração para a sua aplicação.

> **Atenção ⚠️:** Leia o arquivo README.md do projeto com atenção para uma explicação detalhada de como desenvolver e entregar seu projeto.

### Entregáveis

Para entregar o seu projeto, você deverá criar um Pull Request para um repositório no GitHub destinado ao projeto de acordo com a estrutura seguinte:

1 - Abra uma branch para a sua entrega. Ela deve ser aberta a partir da branch principal.

2 - Desenvolva o seu código na sua branch e envie para o Github.

3 - Abra uma Pull Request referente a sua branch.

4 - O avaliador irá verificar o seu código em sua Pull Request.

5 - Após finalizar o seu projeto, responda o quiz.
