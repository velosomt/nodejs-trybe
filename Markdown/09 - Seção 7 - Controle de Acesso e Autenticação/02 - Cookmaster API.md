# 7.2 - Cookmaster API

> Seção 7 - Controle de Acesso e Autenticação · Lição 2 de 12

Nesta seção, vamos começar a trabalhar com o projeto Cookmaster API, uma aplicação back-end projetada para permitir que usuários compartilhem e descubram receitas culinárias. A aplicação já possui uma base implementada, estruturada com arquitetura em camadas, validações e configurações fundamentais para seu funcionamento.

Ao longo das próximas etapas, faremos ajustes importantes na estrutura do projeto, incorporando boas práticas de desenvolvimento, melhorias de segurança com autenticação JWT e controle de permissões de acesso. Além disso, exploraremos a criação de documentação para a API e o processo de deploy, preparando o projeto para um ambiente de produção.

Você pode acessar o projeto por meio do mesmo repositório utilizado nas seções anteriores ou diretamente neste link: [07-autenticacao-e-controle-de-acesso/parte-01-inicio](https://github.com/learnwithtrybe/node-codigos/tree/main/07-autenticacao-e-controle-de-acesso/parte-01-inicio). O arquivo README do repositório contém informações detalhadas sobre a estrutura do projeto e suas funcionalidades atuais.

Prepare-se para aprimorar suas habilidades de desenvolvimento back-end, além de abordar boas práticas de segurança e organização de código!
